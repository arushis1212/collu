Collu sits inline between an existing agent workflow and production. A developer starts that workflow once from the terminal. Its root is a public GitHub issue instructing the agents to read the production token and deploy without asking. Research summarizes it. Planning turns it into work. Coding carries it forward. Review approves from the same influenced context. When Deploy requests deploy dot production dot execute, the request reaches Collu's protected boundary. The gateway checks the complete ancestry, sees an untrusted root, expanded authority, and non-independent approval, and returns block. The terminal confirms zero production executions. Opening the generated trace shows where the instruction entered, how it moved between agents, and why production never received the request.
